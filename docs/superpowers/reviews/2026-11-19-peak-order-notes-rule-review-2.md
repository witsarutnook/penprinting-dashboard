## ของเล็ก

- ข้อความ 4,000 ตัวอักษรบรรทัดเดียว ("กระดาษ" × 222 + ตัวเลข 2,668 ตัว) ใช้ ~1.9 วินาทีต่อการอ่านหนึ่งครั้ง (`:88`) — ต้องจงใจแต่ง; ข้อความที่สุ่มจากของจริงไม่เกิน 7 ms
- "ไสกาว, มุงหลังคา" ติ๊กทั้งคู่ · ช่องว่างล่องหน (zero-width) ระหว่างคำทำให้ "รอง[ZWSP]ปก" เป็นคำว่าปก · บรรทัดแรกที่มีแต่ช่องว่างล่องหนกลายเป็นชื่องานที่มองไม่เห็น (ของเดิมใน `firstLine`)
- `unitNotes` โยน TypeError ถ้า `unit.lineKeys` ไม่ใช่ list (`mapper.ts`; `specForUnit` กันไว้แล้ว) · บรรทัด "สเปกที่อ่านได้" ไม่มีเพดานความยาว (การ์ดตัดที่ 300)
- บรรทัด `ปก` ที่อยู่หลังส่วนไส้ ทำให้บรรทัดถัดไปกลับเป็น "ทั่วไป" → ช่องติ๊กถูกติ๊กในที่ที่ `221eb8b` เว้นว่าง (พฤติกรรมที่เปลี่ยนข้อที่ 5 ของ `e2e5066` ซึ่งไม่ได้เขียนไว้)

## ที่ลองแล้วไม่พัง

- โครงของหมายเหตุ (บรรทัดที่อยู่ไม่ถูกแตะ เรียงเดิม ไม่มีบรรทัดว่างซ้อน อ้างอิง Peak อยู่ท้าย): 0 จาก 489,840
- ขึ้นบรรทัดแบบ CRLF / CR / ช่องว่างท้ายบรรทัด ให้ผลเดียวกัน · ไม่ throw กับค่าแปลก 25 แบบ
- **บรรทัดชื่องานออกเฉพาะเมื่อเป็นชื่องานทั้งบรรทัด** · แบบ "รวมหลายรายการ" ไม่ถูกแตะ
- `4535e07` เทียบ `221eb8b`: ไม่มีช่องไหนเปลี่ยนค่า มีแต่ ว่าง ↔ เติม · ข้อความจริง 48 แถวเหมือนกันทุกช่อง
- ไม่มีตัวอักษรล่องหนใน source ของ `spec-from-text.ts` / `mapper.ts`
