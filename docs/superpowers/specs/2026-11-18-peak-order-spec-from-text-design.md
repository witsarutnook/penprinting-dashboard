# /order จาก Peak — เติมช่องสเปกจากข้อความรายการ

ต่อจาก [[2026-11-14-peak-order-from-line-design]] ซึ่งตั้งใจเว้นไว้ ("ลอกข้อความลงหมายเหตุก่อน แล้วค่อยเพิ่มทีหลัง").

## 1. ทำไม

คุณนุ๊กเปิดใบที่สร้างจาก `/order` (18 พ.ย. 2026) แล้วเห็นว่าสเปกทั้งหมดอยู่ในช่องหมายเหตุ ช่องขนาด / กระดาษ / สี / เคลือบ / เข้าเล่มว่างหมด ต้องอ่านแล้วกรอกซ้ำเอง. ใบที่กด "✅ สร้างงาน" ขึ้นบอร์ดเลยโดยไม่มีใครเปิดฟอร์ม — การ์ดบนบอร์ดจึงไม่มีสเปกเป็นช่องให้ฝ่ายผลิตเห็น.

## 2. เป้าหมาย / ไม่ทำ / ห้ามเกิด

**เป้าหมาย**
- ข้อความรายการที่เขียนสเปกชัด → ช่องในฟอร์มถูกเติมให้ ด้วยคำแบบเดียวกับที่ทีมกรอกเองอยู่แล้ว
- ก่อนกดสร้าง คนที่สั่งเห็นใน LINE ว่าระบบอ่านสเปกได้ว่าอะไร

**ไม่ทำ (รอบนี้)**
- ไม่ใช้ AI — กฎคำหลักล้วน ผลเหมือนเดิมทุกครั้ง ไม่มีค่าใช้จ่ายต่อครั้ง (คุณนุ๊กเลือก 18 พ.ย.)
- ไม่แตะช่องหมายเหตุ — ข้อความต้นฉบับอยู่ครบเหมือนเดิม
- ไม่เติมใบแบบ "รวมหลายรายการ" (หลายรายการในใบเดียว บอกไม่ได้ว่าสเปกของรายการไหน)
- งานบิล (ใบ/ชุด ชุด/เล่ม สีบิล รันเลข), ปั๊มฟอยล์/นูน, ประเภท PLATE, ขนาด PLATE, วัสดุสติกเกอร์ — ตัวอย่างในข้อมูลจริงน้อยเกินจะเขียนกฎให้มั่นใจ
- จำนวนหน้า / พิมพ์กี่หน้า (หน้าเดียว-หน้าหลัง) — ฟอร์มไม่มีช่อง อยู่ในหมายเหตุ

**ห้ามเกิด**
- ติ๊กหรือกรอกค่าที่ข้อความไม่ได้เขียน. **ไม่แน่ใจ = เว้นว่าง** — ช่องว่างเสียหายน้อยกว่าช่องผิด
- ทำให้ `/order` ช้าลงหรือพังเพราะข้อความแปลก — ตัวอ่านเป็นฟังก์ชันล้วน ไม่เรียกอะไรภายนอก ข้อความอะไรก็ต้องไม่ throw

## 3. ข้อมูลจริงที่ใช้ออกแบบ (นับบน production 18 พ.ย. 2026)

| กระดาษ | 84 (มีแกรม 80) | 77% |

**ฝั่งใบสั่งงานเดิม** — 500 ใบล่าสุดที่ทีมกรอกเอง:
- งานแผ่นเดียวกรอก **กระดาษเนื้อใน + สีเนื้อใน**: กรอกเนื้อในอย่างเดียว 344 ใบ (69%) · ทั้งปกและเนื้อใน 122 · ปกอย่างเดียว 25
- ขนาด: พิมพ์ `A4` `A5` `9x5.5` ตรง ๆ หน่วยปล่อยเป็น "ซม." แม้เป็น A4 · งานนิ้วเลือกหน่วย "นิ้ว"
- กระดาษ: ข้อความอิสระ คำเดียวกับในใบเสนอราคา (`อาร์ต 230g`, `ปอนด์ 70g`, `อาร์ตมัน 260 แกรม`) → ลอกตามที่เขียน ไม่ต้องแปลงคำ
- สี: ตัวเลือก `1สี`–`4สี` · หมายเหตุสีที่ใช้จริง = ชื่อสี (`ดำ` 60, `น้ำเงิน` 28, `เขียว` 9)
- ไดคัท: "ไดคัทเอง" 56 ใบ · "ส่งไดคัท" 14 ใบ — ข้อความใบเสนอราคาไม่บอกว่าแบบไหน

## 4. แนวทางที่พิจารณา

| | กฎคำหลัก (เลือก) | AI อ่าน |
|---|---|---|
| ครอบคลุม | เฉพาะคำที่มีกฎ | กว้างกว่า |
| ผิดพลาด | ไม่แน่ใจ = ว่าง | ติ๊กผิดได้โดยไม่มีสัญญาณ |
| ค่าใช้จ่าย / ความเร็ว | ไม่มี / ทันที | มีต่อครั้ง / ช้ากว่า |

คุณนุ๊กเลือกกฎคำหลัก. เหตุผล: "✅ สร้างงาน" ส่งใบขึ้นบอร์ดโดยไม่มีคนตรวจฟอร์ม. ข้อมูลจริงก็สนับสนุน — ทีมเขียนใบเสนอราคาเป็นรูปแบบค่อนข้างคงที่.

## 5. การทำงาน

ตัวอ่านใหม่ `lib/peak-order/spec-from-text.ts` — ฟังก์ชันล้วน `specFromText(description) → { fields, summary }`:
- `fields` = ค่าของช่องฟอร์มเฉพาะที่อ่านได้ (ช่องที่อ่านไม่ได้ไม่อยู่ในผลลัพธ์)
- `summary` = บรรทัดสั้นสำหรับการ์ด LINE เช่น `ขนาด A5 · ปก อาร์ทการ์ดหน้าเดียว 350 แกรม 4สี · เนื้อใน ถนอมสายตา(จริงใจ AA) 75 แกรม 1สี (น้ำเงิน) · เคลือบด้าน · กระดูกงู`

ใช้ 2 ที่ จากข้อความเดียวกัน (รายการของใบเสนอราคาที่เก็บไว้ในร่าง — ไม่อ่าน Peak เพิ่ม):
1. **การ์ดสรุปใน LINE** — เพิ่มบรรทัด "สเปกที่อ่านได้: …" (ไม่มีอะไรอ่านได้ = ไม่แสดงบรรทัดนี้)
2. **ตอนสร้างใบ** — ทั้ง "✅ สร้างงาน" และ "📝 บันทึกเป็นใบร่าง" → ค่าใน `fields` ลงฟอร์ม

เฉพาะใบที่ 1 ใบสั่งงาน = 1 รายการ (ใบรายการเดียว และแบบ "แยก"). แบบ "รวม" ไม่เติม.

### 5.1 แบ่งส่วน ปก / เนื้อใน

อ่านทีละบรรทัดจากบนลงล่าง:
- เจอ `เนื้อใน` → ข้อความถัดจากนั้นเป็นของเนื้อใน · เจอ `ปก` ที่ขึ้นต้นคำ (ต้นบรรทัด หรือหลังช่องว่าง/ตัวเลข — `รองปก` `รวมปก` `หน้าปก` ไม่นับ) → เป็นของปก
- บรรทัดถัดไปที่ไม่มีคำบอกส่วน → เป็นของส่วนล่าสุด (ตัวอย่างจริง: `เนื้อใน 80 แผ่น(160หน้า)` แล้วบรรทัดถัดไป `กระดาษถนอมสายตา… พิมพ์ 1 สี-น้ำเงิน`)
- ทั้งข้อความไม่มี `ปก` / `เนื้อใน` เลย → งานแผ่นเดียว: กระดาษและสีลง **ช่องเนื้อใน** (ตามที่ทีมกรอกจริง 69%)
- ข้อความมีส่วนแล้ว แต่กระดาษ/สีอยู่ก่อนถึงส่วนแรก → ไม่เติม — ยกเว้นสีที่เขียนว่า `ทั้งเล่ม` (ข้อ 10)

### 5.2 กฎรายช่อง

| ช่อง | อ่านจาก | ตัวอย่างจริง → ค่า |
|---|---|---|
| `size` + `sizeUnit` | `A3`–`A6` / `เอ 4` → `A4` (หน่วยคง "ซม." ตามที่ทีมกรอก) · `กว้างxยาว[xสูง]` + หน่วย (`ซม.` `cm` → ซม. · `นิ้ว` → นิ้ว · `มม.` `mm` → มม.) ตัวคั่น `x` `×` `*` | `ขนาด 9x5.5 ซม.` → `9x5.5` ซม. · `ขนาด 10*14 ซม.` → `10x14` ซม. · `ขนาดเอ 5` → `A5` · `15x21 นิ้ว` → `15x21` นิ้ว |
| `paperCover` / `paperInner` | หลังคำ `กระดาษ` หรือหลัง `ปก` / `เนื้อใน` จนจบน้ำหนัก (`แกรม` `กรัม` `g` `gsm`) — ลอกตามที่เขียน ตัดคำว่า "กระดาษ" ออก | `กระดาษอาร์ตมัน 260 แกรม` → `อาร์ตมัน 260 แกรม` · `ปกอาร์ต 230 แกรม` → ปก `อาร์ต 230 แกรม` · `เนื้อในกระดาษปอนด์ 100` → เนื้อใน `ปอนด์ 100` |
| `coverColor` / `innerColor` | `N สี` (1–4) · `สีเดียว` → `1สี` · `ขาวดำ` → `1สี` | `พิมพ์ 4 สี` → `4สี` · `พิมพ์สีเดียว` → `1สี` |
| `coverColorNote` / `innerColorNote` | ชื่อสีที่ตามหลังจำนวนสีทันที: หลัง `-` · ในวงเล็บ · หรือคำชื่อสี (ดำ แดง น้ำเงิน เขียว ฟ้า ชมพู เหลือง ส้ม ม่วง ทอง เงิน น้ำตาล) ในบรรทัดเดียวกัน | `1 สี-น้ำเงิน` → `น้ำเงิน` · `2 สี (แดง ดำ)` → `แดง ดำ` · `1 สี 1 หน้า สีทอง` → `ทอง` |
| `coatMatte` | `เคลือบ…ด้าน` (รวม `เคลือบลามิเนตด้าน`) | `เคลือบด้าน 2 หน้า` → ✓ |
| `coatGloss` | `เคลือบ…เงา` | `เคลือบเงา` → ✓ |
| `coatUV` / `coatSpotUV` | `เคลือบ UV` / `Spot UV` `สปอตยูวี` | `เคลือบ UV` → ✓ |
| `glue` | `ไสกาว` | `เข้าเล่มไสกาวปกอ่อน` → ✓ |
| `saddle` | `มุงหลังคา` (ไม่ผูกกับคำว่า "เย็บ" — มีพิมพ์ผิดเป็น "เย็ม") | `เย็บมุงหลังคา` → ✓ |
| `spine` (กระดูกงู) | `กระดูกงู` · `เข้าห่วง` · `ห่วงลวด` | `เข้าเล่มแบบห่วงลวดกระดูกงู` → ✓ — **ดูข้อ 7.1** |
| `perf` | `ปรุ` (ไม่นับ `ปรุ๊ฟ` ซึ่งเป็นชื่อกระดาษ) | `ปรุ 5 ตอน` → ✓ |
| `digital` | `ดิจิตอล` `ดิจิทัล` `Digital` | `ปริ้น Digital` → ✓ |
| `diecut` / `diecutSelf` | — | **ไม่ติ๊ก — ดูข้อ 7.2** |

### 5.3 เมื่อไรเว้นว่าง

- **ช่องเดียวเจอ 2 ค่าไม่เหมือนกัน** → ช่องนั้นว่าง. `เนื้อในกระดาษปอนด์ 100` + `กระดาษเปล่า 70g รองปก` → กระดาษเนื้อในว่าง · `4 สี 12 หน้า ขาวดำ 128 หน้า` → สีว่าง. (ค่าเดียวกันซ้ำ 2 ครั้งไม่นับว่าขัดกัน · ปฏิทินที่มีป้าย + ภู่/ไส้ ดูข้อ 10)
- **ขนาด**: ถ้ามีค่าที่ตามหลังคำว่า `ขนาด` ใช้ค่านั้น ไม่สนค่าอื่นในข้อความ (`ตัด 4 ขนาด 15x21 นิ้ว … ไส้ 7x15 นิ้ว` → `15x21`). ค่าที่มี `กางออก` `1/3` นำหน้า, `ครึ่ง` + กว้างxยาว, กว้างxยาวที่ไม่บอกหน่วย, และขนาดแบบ `สูง12" ยาว15" กว้าง6"` → ว่าง (`ครึ่ง` + ขนาด A ดูข้อ 10)
- **กระดาษ**: ต้องมีน้ำหนัก หรือขึ้นต้นด้วยชื่อกระดาษที่รู้จัก (อาร์ต ปอนด์ การ์ด ถนอมสายตา น้ำตาล คาร์บอน กล่องแป้ง ปรู๊ฟ) — กัน `กระดาษหัวจดหมาย` `กระดาษคำตอบ` ที่เป็นชื่องาน. ยาวเกิน 60 ตัวอักษร → ว่าง
- **เคลือบ** ที่มี `หรือ` (`เคลือบเงาหรือด้าน`) → ไม่ติ๊กทั้งคู่

## 6. ข้อที่ Claude ตัดสินเอง (คุณนุ๊กแก้ได้)

1. งานแผ่นเดียวลงช่อง **เนื้อใน** — ตามที่ทีมกรอกจริง
2. เจอ 2 ค่าขัดกัน = **ว่าง** ไม่ใช้ค่าแรก
3. เติมทั้งตอน "สร้างงาน" และ "ใบร่าง" · ไม่เติมแบบ "รวม"
4. การ์ดสรุปใน LINE แสดงบรรทัด "สเปกที่อ่านได้" — ให้คนสั่งเห็นก่อนกด
5. ไม่มีสวิตช์เปิด/ปิดแยก — ถ้ามีปัญหา revert commit
6. กฎทุกข้อต้องมีตัวอย่างจากใบเสนอราคาจริง — คำที่ยังไม่เคยเห็นไม่เขียนกฎเผื่อ
7. คำนวณจากรายการที่เก็บในร่าง ไม่เพิ่มข้อมูลในตาราง → ร่างที่ค้างอยู่ตอน deploy ได้สเปกด้วย

## 7. รอคุณนุ๊กตอบ

> ✅ **ตอบแล้ว 2026-11-18 — ตามที่เสนอทั้ง 2 ข้อ**: (1) `spine` = กระดูกงู ตามฟอร์ม · `เข้าห่วง / กระดูกงู` ติ๊กช่องนี้ · แก้ป้ายในหน้าต่างรายละเอียด + "เย็บที่" → "เย็บกี่" (2) ไดคัท ไม่ติ๊ก

1. **ช่อง `spine`** — ฟอร์มและใบพิมพ์ A4 เขียนว่า **"กระดูกงู"** แต่หน้าต่างรายละเอียดบนบอร์ด / `/orders` เขียนว่า **"สันธรรมดา"** (ช่องเดียวกัน). ข้อเสนอ: ถือตามฟอร์ม = กระดูกงู, ให้ `เข้าห่วง / กระดูกงู` ติ๊กช่องนี้, แล้วแก้ป้ายในหน้าต่างรายละเอียดให้ตรง (พร้อมแก้ "เย็บที่" ในฟอร์มเป็น "เย็บกี่" ตามใบพิมพ์)
2. **ไดคัท** — ข้อความเขียนแค่ "ไดคัท" แต่ฟอร์มมี 2 ช่อง (ส่งไดคัท / ไดคัทเอง). ข้อเสนอ: ไม่ติ๊ก. ถ้าร้านมีกฎตายตัว (เช่น สติกเกอร์ = ไดคัทเอง) บอกได้ จะเขียนเป็นกฎ

## 8. วิธียืนยันก่อนเปิดใช้

1. เทสต์ของตัวอ่าน: ตัวอย่างจากข้อความจริงทุกกฎ + ทุกกรณี "เว้นว่าง" ในข้อ 5.3 (RED ก่อน)
2. **รันตัวอ่านกับ 109 รายการจริงบน production** (ต่อยอดตัวอ่านชั่วคราว) → ตารางผลรายรายการให้คุณนุ๊กดูว่าเติมถูกไหม **ก่อน** ต่อเข้ากับการสร้างใบ
3. คุณนุ๊กโอเค → ต่อเข้า `/order` + การ์ดสรุป → deploy → สั่ง 1 ใบจริงในกลุ่ม เปิดฟอร์มเทียบ
4. ลบตัวอ่านชั่วคราว (route + เทสต์)

## 9. เหลือให้คนทำตัดสิน

- รูปแบบ regex และลำดับการจับคู่ภายในบรรทัด
- ความยาวสูงสุดของบรรทัด "สเปกที่อ่านได้" บนการ์ด (ต้องไม่เกินข้อจำกัด Flex ที่มีอยู่)
- ชื่อฟังก์ชัน / โครงไฟล์เทสต์

## 10. ปรับกฎหลังคุณนุ๊กดูตารางจริง (18 พ.ย. 2026)

รันตัวอ่านกับ 72 ใบ / 111 รายการจริงบน production แล้วให้คุณนุ๊กดูตาราง — ไม่มีแถวไหนถูกบอกว่าเติมผิด คุณนุ๊กสั่งปรับ 3 ข้อ และยืนยัน 2 ข้อ:

| คุณนุ๊กสั่ง | กฎ |
|---|---|
| "ขนาดครึ่ง A4 = A5" | `ครึ่ง` + ขนาด A3–A6 → ขนาด A ถัดไป (ครึ่งเอ 4 → `A5`). `ครึ่ง` + กว้างxยาว ยังเว้นว่าง *(Claude ขยายจาก A4 เป็น A3–A6 เพราะเป็นนิยามของขนาด A)* |
| "พิมพ์ 4 สี ทั้งเล่ม ติ๊กทั้งปกและเนื้อในเป็น 4สี" | `N สี ทั้งเล่ม` ที่อยู่นอกส่วน ปก/เนื้อใน → ลงทั้ง **สีปก** และ **สีเนื้อใน**. ถ้าอยู่ในส่วนแล้ว (`เนื้อใน 4 สีทั้งเล่ม`) เป็นสีของส่วนนั้นอย่างเดียว *(Claude ตัดสิน — กันเคส `ปก 1 สี / เนื้อใน 4 สีทั้งเล่ม`)* |
| "ปฏิทินลงแต่ขนาดป้ายได้เลย ภู่/ไส้ ใส่หมายเหตุแทน" | ข้อความที่มีคำว่า `ปฏิทิน`: ตั้งแต่คำว่า `ภู่` / `ไส้` เป็นต้นไป (จนเจอ `ป้าย` / `ปก` / `เนื้อใน`) **ไม่ลงช่องใดเลย** — อยู่ในหมายเหตุตามเดิม. ช่องขนาด กระดาษ สี เคลือบ จึงเป็นของป้าย *(Claude ตีความว่ารวมกระดาษ/สี/เคลือบของภู่-ไส้ด้วย ไม่ใช่แค่ขนาด — คุณนุ๊กดูผลในตารางรอบสอง)* |
| "กางออก — ว่าง" | คงเดิม |
| "เงาหรือด้าน / ไดคัท — โอเค" | คงเดิม (ไม่ติ๊ก) |

ข้อที่คุณนุ๊กไม่ได้ตอบ: สมุด Passport ที่มีกระดาษ 2 ชนิดในส่วนเนื้อใน → **คงเว้นว่าง**.

## 11. กฎกันอ่านผิด — จากผู้ตรวจอิสระ (18 พ.ย. 2026)

ผู้ตรวจอิสระลองข้อความราว 170 แบบกับตัวอ่าน: การต่อโค้ดถูกต้อง (ไม่ throw · ทับค่าที่คนเลือกไม่ได้ · การ์ดกับใบที่สร้างอ่านตรงกันเสมอ) แต่ **กฎอ่านผิดได้กับประโยคที่ต่างจากข้อความจริงไปหนึ่งขั้น**. แก้ทุกข้อที่ทำให้เติมผิด โดยยึดหลักเดิม "ไม่แน่ใจ = ว่าง" — เทสต์ 59 รายการล้มก่อนแก้ทุกตัว:

| เรื่อง | ข้อความที่เคยอ่านผิด | ตอนนี้ |
|---|---|---|
| ส่วนปก | `หนังสือ ปกอ่อน ขนาด A5 ⏎ กระดาษปอนด์ 80 แกรม…` (กระดาษเนื้อในถูกลงช่องปก) | `ปกอ่อน` `ปกแข็ง` เป็นชนิดเข้าเล่ม ไม่เปิดส่วนปก · **ส่วนปกมีผลแค่บรรทัดของมันเอง** ไม่ลามไปบรรทัดถัดไป (ส่วนเนื้อในยังต่อบรรทัดได้ตามข้อความจริง) |
| เคลือบ | `เคลือบเงา/ด้าน` · `…หรือเงา` ท้ายบรรทัด · `ไม่ต้องเคลือบด้าน` · `ไม่มีเคลือบ UV` · `หากเคลือบด้าน เพิ่ม…` · `เคลือบด้านหน้า UV` / `ด้านเดียว` (ด้าน = ข้าง) · รายการตัวเลือก เงา + ด้าน | ไม่ติ๊ก · `เคลือบ UV เฉพาะจุด` = Spot UV |
| ขนาด | `ขนาด A4 หรือ A5` · `A4/A5` · ขนาดซอง/บล็อกฟอยล์ที่เขียนทีหลัง · `1/4 A4` · `ครึ่งหน้า A4` · `A4 ครึ่งแผ่น` · `8 1/2 x 11 นิ้ว` · `60x160 "ข้อความ"` · `ดีเอ็นเอ 5` · `A3+` | ว่าง. ขนาดหลังคำว่า "ขนาด" ชนะขนาดอื่นได้เฉพาะเมื่อเป็นขนาดแรกในข้อความ อยู่บรรทัดนั้นขนาดเดียว และไม่มี "ขนาด …" อื่นที่ต่างกัน |
| จำนวนสี | `4/1 สี` · `4+1 สี` · `1-2 สี` · `กระดาษคาร์บอน 3 สี` · `ปั๊มฟอยล์ 2 สี` · `สติ๊กเกอร์ PVC ขาว ดำ` · `สีเดียวกัน` | ว่าง. นับ "N สี" เมื่อมีคำว่า พิมพ์/ปริ้น/สกรีน นำหน้า (และไม่มี "กระดาษ" คั่น) หรืออยู่ต่อจาก ปก/เนื้อใน |
| ชื่อสี | `หูเชือกสีดำ` · `ฟอยล์สีทอง` · `(ใบเสร็จรับเงิน)` · `น้ำเงินเข้ม` | ไม่ลงหมายเหตุสี. วงเล็บต้องมีแต่ชื่อสี · ชื่อสีต้องเป็นคำเต็ม |
| Digital | ชื่องาน `Digital Marketing` · `ปรู๊ฟดิจิตอล` · `ไม่ใช่ดิจิตอล` | ไม่ติ๊ก. ต้องมี พิมพ์/ปริ้น นำหน้า |
| กระดาษ | `230 แกรม หรือ 260 แกรม` (เคยตัดเหลือ 230) · `ถุงกระดาษรับน้ำหนักได้ 500 กรัม` · `ปก artwork เดิม` | ลอกทั้ง 2 น้ำหนักตามที่เขียน · สองอันหลังไม่ใช่กระดาษ |
| เข้าเล่ม / ปรุ | `ไสกาว หรือ มุงหลังคา` · `ไม่ปรุ` · `ไม่ไสกาว` · `รับมุงหลังคาเมทัลชีท` | ไม่ติ๊ก |
| ข้อความยาวเกิน 4,000 ตัวอักษร | ตัดกลางคำ (`อาร์ต 23`) | อ่านเฉพาะบรรทัดที่ครบก่อนถึงขีดจำกัด |

หลักที่ใช้ร่วมกันทุกช่องติ๊ก: บรรทัดที่มี **"หรือ"** = ตัวเลือก ไม่ติ๊กอะไรในบรรทัดนั้น · คำว่า **ไม่ / หาก / ถ้า / ยกเว้น** ก่อนคำนั้นในบรรทัดเดียวกัน = ไม่ติ๊ก.

ผลข้างเคียงที่ยอมรับ (ว่างเพิ่มขึ้น): `ขนาด 21x29.7 ซม. (A4)` (2 ขนาดในบรรทัดเดียว) · `ขนาด A4 4 สี` ที่ไม่มีคำว่าพิมพ์ · บรรทัดที่ไม่มีคำบอกส่วนซึ่งอยู่ถัดจากบรรทัดปก.

เทสต์ของตัวอ่าน 84 → 168 · จงใจทำกฎพัง 75 จุด เทสต์จับได้ครบ 75.

**เพิ่มจากใบเสนอราคาจริงที่เข้ามาระหว่างรันรอบสอง** (`หนังสือขนาด A6 ⏎ ปกแข็ง พิมพ์ 4 สี ⏎ เนิ้อในถนอมสายตา 24 หน้า ⏎ พิมพ์ 1 สี`): `ปกแข็ง` / `ปกอ่อน` ที่ **ขึ้นต้นบรรทัด** = ส่วนปก (กลางบรรทัด = ชนิดเข้าเล่ม) · `เนิ้อใน` (พิมพ์ผิดจากเนื้อใน) = เนื้อใน · ชื่อกระดาษจบที่จำนวนหน้า/แผ่น (`ถนอมสายตา 24 หน้า` → `ถนอมสายตา`). เทสต์ 168 → 171 · จงใจทำกฎพัง 78 จุด จับได้ครบ.
